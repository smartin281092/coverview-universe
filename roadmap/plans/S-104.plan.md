## Definition of Done — critères et oracles

### S-104-C01

Formation/événement exige présence ou complétion, règle de campagne et plafond ; revue/étape utile exige un événement réellement terminé non répétable abusivement.

- Oracle : **V2**.
- Vérification à exécuter : Rejouer la complétion d’une formation et d’une revue : un gain par source, aucun gain pour simple ouverture de page.
- Sources : [bible.v15.t093r002](../../docs/product/bible.extracted.md#p1909), [bible.v15.t093r005](../../docs/product/bible.extracted.md#p1915), [bible.v15.t106r013](../../docs/product/bible.extracted.md#p2781)

### S-104-C02

Achat de prestation attend paiement ou délai d’annulation validé ; signature+activation de contrat peut rester pending durant contrôles/renonciation/reprise.

- Oracle : **V2**.
- Vérification à exécuter : Paiement en échec donne zéro disponible ; contrat pending puis contrôles validés devient disponible une seule fois.
- Sources : [bible.v15.t093r003](../../docs/product/bible.extracted.md#p1911), [bible.v15.t093r004](../../docs/product/bible.extracted.md#p1913)

### S-104-C03

Action partenaire/parrainage/campagne exige preuve, financement, éligibilité, plafond et déduplication ; cas suspects sont bloqués ou revus selon règle.

- Oracle : **V2**.
- Vérification à exécuter : Auto-parrainage et preuve transaction absente sont refusés ; événement partenaire dupliqué n’ajoute pas de Miles.
- Sources : [bible.v15.t093r006](../../docs/product/bible.extracted.md#p1917), [bible.v15.t093r007](../../docs/product/bible.extracted.md#p1919), [bible.v15.t097r017](../../docs/product/bible.extracted.md#p2304)

- Oracle : **V3**.

- Sources : [bible.v15.p1922](../../docs/product/bible.extracted.md#p1922), [bible.v15.p1923](../../docs/product/bible.extracted.md#p1923), [bible.v15.p2161](../../docs/product/bible.extracted.md#p2161), [bible.v15.t099r020](../../docs/product/bible.extracted.md#p2374), [bible.v15.p0029](../../docs/product/bible.extracted.md#p0029), [bible.v15.p0292](../../docs/product/bible.extracted.md#p0292), [bible.v15.t021r020](../../docs/product/bible.extracted.md#p0377), [bible.v15.p2931](../../docs/product/bible.extracted.md#p2931)

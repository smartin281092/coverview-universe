### S-018-C01

Les transitions DRAFT/READY_TO_SIGN/AWAITING_SIGNATURE/SIGNED/VALIDATED et sorties DECLINED/EXPIRED/CANCELLED sont persistantes et interdites hors transitions documentées.

- Oracle : **V2**.
- Vérification à exécuter : Table de transitions couvrant expiration, refus, annulation et callback tardif ; aucune réactivation silencieuse.
- Sources : [bible.v15.t039r001](../../docs/product/bible.extracted.md#p0772)

### S-018-C02

La preuve contient document exact, version/hash, signataire, date/heure, méthode d’authentification, consentement, adresse technique utile et événements ; accès à la preuve reste protégé.

- Oracle : **V2**.
- Vérification à exécuter : Signer une fixture puis vérifier hash, contenu et permissions des artefacts archivés.
- Sources : [bible.v15.p0274](../../docs/product/bible.extracted.md#p0274), [bible.v15.p0770](../../docs/product/bible.extracted.md#p0770)

### S-018-C03

Après lecture/consentement, une modification de document impose une nouvelle session ; un signataire différent et un callback invalide sont refusés sans valider le dossier.

- Oracle : **V2**.
- Vérification à exécuter : Essayer substitution document et callback forgé ; hash et signature finale restent liés à la version consentie.
- Sources : [bible.v15.p0770](../../docs/product/bible.extracted.md#p0770), [bible.v15.t039r001](../../docs/product/bible.extracted.md#p0772), [bible.v15.p0774](../../docs/product/bible.extracted.md#p0774), [bible.v15.p0780](../../docs/product/bible.extracted.md#p0780), [bible.v15.p0781](../../docs/product/bible.extracted.md#p0781)

### S-018-C04

Signature finalisée met à jour le workflow et rend document/preuve immédiatement accessibles dans Wallet/Admin ; retry et événements hors ordre ne créent qu’une transition métier logique.

- Oracle : **V2**.
- Vérification à exécuter : Redélivrer trois callbacks puis recharger Wallet et Admin : une preuve, une activité, même statut.
- Sources : [bible.v15.p0782](../../docs/product/bible.extracted.md#p0782), [bible.v15.p0783](../../docs/product/bible.extracted.md#p0783), [bible.v15.t102r007](../../docs/product/bible.extracted.md#p2420)

Le parcours affiche explicitement signature de test, état en attente, refus/expiration et nouvelle tentative autorisée ; le niveau juridique reste non déclaré avant S-035.

- Oracle : **V3**.

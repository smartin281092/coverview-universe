## Definition of Done — critères et oracles

### S-101-C01

La carte est un pass membre/fidélité, jamais identité/assurance/authentification ; ajout est proposé seulement pour plateforme/appareil compatibles.

- Oracle : **V3**.
- Vérification à exécuter : Créer deux instances de fixture et lire leur nature simulée ; une plateforme incompatible offre accès Wallet sans faux ajout natif.

### S-101-C02

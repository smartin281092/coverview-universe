## Definition of Done — critères et oracles

### S-103-C01

Le solde est somme d’écritures immuables ; correction crée adjustment/reversal avec motif, jamais UPDATE silencieux de l’historique.

- Oracle : **V2**.
- Vérification à exécuter : Enregistrer 100 puis adjustment -20 en fixture ; solde 80, écriture 100 inchangée ; mutation d’écriture refusée.
- Sources : [bible.v15.p1906](../../docs/product/bible.extracted.md#p1906), [bible.v15.t106r013](../../docs/product/bible.extracted.md#p2781), [bible.v15.p0292](../../docs/product/bible.extracted.md#p0292), [bible.v15.t021r020](../../docs/product/bible.extracted.md#p0377)

### S-103-C02

Statuts pending/available/reserved/redeemed/expired/reversed/adjusted restent distincts et les transitions respectent une règle validée.

- Oracle : **V2**.
- Vérification à exécuter : Pending 100 n’est pas consommable ; réserver 40 sur available 100 donne disponible 60 et réservé 40, sans double comptage.
- Sources : [bible.v15.p1921](../../docs/product/bible.extracted.md#p1921), [bible.v15.p2554](../../docs/product/bible.extracted.md#p2554)

### S-103-C03

Chaque écriture expose règle/version/source/date/expiration éventuelle/financeur/motif ; changement de règle ne recalcule pas l’historique.

- Oracle : **V3**.
- Vérification à exécuter : Changer une règle v2 puis ouvrir un gain v1 : preuve et règle initiales toujours affichées.
- Sources : [bible.v15.p1922](../../docs/product/bible.extracted.md#p1922), [bible.v15.p1923](../../docs/product/bible.extracted.md#p1923)

### S-103-C04

Reversal d’annulation/défaut/reprise et ajustement manuel sont explicites, motivés, audités et soumis aux droits/double validation décidés.

- Oracle : **V2**.
- Vérification à exécuter : Sans motif ou droit, correction refusée ; rejouer même reversal n’ajoute pas une seconde déduction.
- Sources : [bible.v15.p1924](../../docs/product/bible.extracted.md#p1924), [bible.v15.p2162](../../docs/product/bible.extracted.md#p2162)

### S-103-C05

Opérations atomiques et idempotentes empêchent double dépense et solde négatif non autorisé, y compris sous concurrence.

- Oracle : **V2**.
- Vérification à exécuter : Deux réservations simultanées de 80 sur 100 : au plus une réussit ; solde dérivé jamais négatif.
- Sources : [bible.v15.p2553](../../docs/product/bible.extracted.md#p2553), [bible.v15.p2554](../../docs/product/bible.extracted.md#p2554), [bible.v15.p0029](../../docs/product/bible.extracted.md#p0029)

### S-103-C06

Client voit historique complet et Admin rapproche comptes/statuts/écarts ; suppression d’un pass ne supprime aucune écriture.

- Oracle : **V3**.
- Vérification à exécuter : Parcourir toutes les écritures du cas de fixture puis révoquer le pass ; historique inchangé et total Admin identique.
- Sources : [bible.v15.p1952](../../docs/product/bible.extracted.md#p1952), [bible.v15.p2161](../../docs/product/bible.extracted.md#p2161), [bible.v15.p2559](../../docs/product/bible.extracted.md#p2559), [bible.v15.p2600](../../docs/product/bible.extracted.md#p2600), [bible.v15.p0040](../../docs/product/bible.extracted.md#p0040), [bible.v15.t097r017](../../docs/product/bible.extracted.md#p2304), [bible.v15.t102r034](../../docs/product/bible.extracted.md#p2474)

### S-103-C07

Miles sont par défaut non monétaires/non transférables tant qu’aucune décision contraire n’est approuvée ; aucune équivalence CHF implicite dans les vues.

- Oracle : **V2**.
- Vérification à exécuter : API refuse transfert et affichage n’invente aucun taux CHF/Mile ; barème fixture identifié comme tel.
- Sources : [bible.v15.p1953](../../docs/product/bible.extracted.md#p1953), [bible.v15.p2931](../../docs/product/bible.extracted.md#p2931)

## Definition of Done — critères et oracles

### S-135-C01

Le LLM passe exclusivement par une gateway et des outils typés autorisés ; les données utilisateur, documents et sorties outils ne deviennent pas des instructions.

- Oracle : **V2**.
- Vérification à exécuter : Corpus adversarial versionné : instruction injectée dans CGA/PDF/email, demande SQL/secrets et exfiltration ; aucune donnée hors droits ni action induite.
- Sources : [bible.v15.p2533](../../docs/product/bible.extracted.md#p2533), [bible.v15.p2534](../../docs/product/bible.extracted.md#p2534), [bible.v15.p2535](../../docs/product/bible.extracted.md#p2535), [bible.v15.p2536](../../docs/product/bible.extracted.md#p2536)

### S-135-C02

Les effets sensibles exigent une confirmation du contenu exact courant, expirent si celui-ci change et laissent une trace sans chaîne de pensée privée.

- Oracle : **V2**.
- Vérification à exécuter : Changer destinataire ou montant après aperçu puis confirmer l’ancien : refus ; confirmer la bonne version une fois puis rejouer : un seul effet.
- Sources : [bible.v15.p2537](../../docs/product/bible.extracted.md#p2537), [bible.v15.p2538](../../docs/product/bible.extracted.md#p2538), [bible.v15.p2541](../../docs/product/bible.extracted.md#p2541)

### S-135-C03

Sans LLM, les parcours manuels fonctionnent ; réponses de couverture distinguent fait, inférence et déclaration, citent la bonne version et escaladent l’incertitude.

- Oracle : **V3**.
- Vérification à exécuter : LLM indisponible, contrat expiré, exclusion manquante et question ambiguë : UI manuelle utilisable, pas de garantie inventée, sources valides et dossier créé.
- Sources : [bible.v15.p2540](../../docs/product/bible.extracted.md#p2540), [bible.v15.p2543](../../docs/product/bible.extracted.md#p2543), [bible.v15.p2544](../../docs/product/bible.extracted.md#p2544), [bible.v15.p2545](../../docs/product/bible.extracted.md#p2545), [bible.v15.p2546](../../docs/product/bible.extracted.md#p2546), [bible.v15.p2547](../../docs/product/bible.extracted.md#p2547), [bible.v15.p2548](../../docs/product/bible.extracted.md#p2548), [bible.v15.p2549](../../docs/product/bible.extracted.md#p2549), [bible.v15.p2550](../../docs/product/bible.extracted.md#p2550)

### S-107-C02

- Oracle : **V2**.

- Sources : [ancrages exacts du critère dans le plan](../plans/S-107.plan.md#s-107-c02)

- Sources : [ancrages exacts du critère dans le plan](../plans/S-107.plan.md#s-107-c03)

## Critères de fin et vérifications à exécuter

### S-053-C01

Le Range présente trois niveaux de vie et associe le « plancher sécurisé » à une probabilité modélisée, sans garantie ni mapping arbitraire.

- Oracle : **V3**.
- Vérification à exécuter : Ouvrir un résultat et sa définition ; vérifier correspondance au mapping approuvé ou état non calculable si non défini.
- Sources : [ancrages exacts du critère dans le plan](../plans/S-053.plan.md#s-053-c01)

### S-053-C02

Les sept métriques demandées sont disponibles ou explicitement indisponibles selon les données : succès réel, valeur économique à vie, break-even, patrimoine P10/P50/P90, dépendance, vente forcée, Lombard.

- Vérification à exécuter : Comparer les sorties au fixture de référence de chaque métrique ; aucune division par zéro, unité ambiguë ou valeur calculée côté UI.
- Sources : [ancrages exacts du critère dans le plan](../plans/S-053.plan.md#s-053-c02)

### S-053-C03

Le résultat distingue réel/nominal, essentiel/confort/idéal, fait/hypothèse/probabilité/recommandation, et montre les raisons de gain comme d'échec.

- Oracle : **V3**.
- Vérification à exécuter : Inspecter scénario favorable puis défavorable et risque de queue ; ouvrir les explications sur une surface dédiée.
- Sources : [ancrages exacts du critère dans le plan](../plans/S-053.plan.md#s-053-c03)

### S-053-C04

Une mention visible unique donne le N réellement exécuté et mène aux détails de méthode ; elle ne répète pas N sous chaque indicateur.

- Oracle : **V3**.
- Vérification à exécuter : Observer résultat complet et panneau méthode ; N demandé différent de N exécuté reste visible dans le détail.
- Sources : [ancrages exacts du critère dans le plan](../plans/S-053.plan.md#s-053-c04)

### S-053-C05

Aujourd'hui restitue Range, réussite, mix et prochaines décisions dans la même version de plan, via l'API autorisée.

- Oracle : **V2**.
- Vérification à exécuter : Lire résultat d'une ancienne version, contrôler sa stabilité et refuser un identifiant de run tiers.
- Sources : [ancrages exacts du critère dans le plan](../plans/S-053.plan.md#s-053-c05)

### S-053-C06

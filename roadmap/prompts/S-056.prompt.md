- Oracle : **V2**.

### S-056-C02

Le snapshot conserve marchés, macro, vie et décisions : rendements/volatilités/corrélations/dividendes, inflation/taux/devises utiles, couple/décès/EMS, budgets/héritage/mix/politique.

- Oracle : **V2**.
- Vérification à exécuter : Inspection d'un run complet et reproduction exacte ; une dimension requise absente bloque le profil concerné.
- Sources : [ancrages exacts du critère dans le plan](../plans/S-056.plan.md#s-056-c02)

### S-056-C03

Le job supporte lancement idempotent, réutilisation, erreur et reprise ; l'API ne garde pas une requête ouverte durant le calcul lourd.

- Oracle : **V2**.
- Vérification à exécuter : Double lancement/retry worker, interruption et redémarrage ; un résultat final et état cohérent sans duplication.
- Sources : [ancrages exacts du critère dans le plan](../plans/S-056.plan.md#s-056-c03)

### S-056-C04

- Sources : [ancrages exacts du critère dans le plan](../plans/S-056.plan.md#s-056-c04)

### S-056-C05

Les diagnostics distinguent convergence, coût/durée, N demandé/exécuté et méthode réelle ; atteindre le nombre cible seul ne certifie aucune queue de distribution.

### S-029-C02

- Oracle : **V2**.

### S-029-C03

- Oracle : **V2**.
- Vérification à exécuter : Vérifier trajectoires fabriquées à seuils précis, franchissements non monotones et cas aucun âge ; borne/capital égal inclus selon définition source.
- Sources : [ancrages exacts du critère dans le plan](../plans/S-029.plan.md#s-029-c03)

- Sources : [ancrages exacts du critère dans le plan](../plans/S-029.plan.md#s-029-c04)

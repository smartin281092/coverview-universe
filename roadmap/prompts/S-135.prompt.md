## Critères de fin et vérifications à exécuter

### S-135-C01

Le LLM passe exclusivement par une gateway et des outils typés autorisés ; les données utilisateur, documents et sorties outils ne deviennent pas des instructions.

- Oracle : **V2**.
- Vérification à exécuter : Corpus adversarial versionné : instruction injectée dans CGA/PDF/email, demande SQL/secrets et exfiltration ; aucune donnée hors droits ni action induite.
- Sources : [ancrages exacts du critère dans le plan](../plans/S-135.plan.md#s-135-c01)

### S-135-C02

Les effets sensibles exigent une confirmation du contenu exact courant, expirent si celui-ci change et laissent une trace sans chaîne de pensée privée.

- Oracle : **V2**.
- Vérification à exécuter : Changer destinataire ou montant après aperçu puis confirmer l’ancien : refus ; confirmer la bonne version une fois puis rejouer : un seul effet.
- Sources : [ancrages exacts du critère dans le plan](../plans/S-135.plan.md#s-135-c02)

### S-135-C03

Sans LLM, les parcours manuels fonctionnent ; réponses de couverture distinguent fait, inférence et déclaration, citent la bonne version et escaladent l’incertitude.

- Oracle : **V3**.
- Vérification à exécuter : LLM indisponible, contrat expiré, exclusion manquante et question ambiguë : UI manuelle utilisable, pas de garantie inventée, sources valides et dossier créé.
- Sources : [ancrages exacts du critère dans le plan](../plans/S-135.plan.md#s-135-c03)

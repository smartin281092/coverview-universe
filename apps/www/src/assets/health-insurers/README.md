# Logos des assureurs du comparateur

Inventaire 2027 : 32 identifiants juridiques, 32 actifs. Recherche et téléchargement du 1 octobre 2026 depuis les sites officiels ou leurs CDN référencés. `provenance.json` contient l'URL, la page d'origine, la date et le SHA-256 de chaque actif.

Fichiers nommés par identifiant OFSP, pas par rapprochement approximatif de nom. Groupe Mutuel est l'identité commerciale affichée par les sites de Mutuel Assurance et Philos ; sana24.ch redirige vers le site de Visana. Ces associations visuelles ne fusionnent ni les entités tarifaires ni leurs conditions. Galenos utilise un logo blanc présenté sur une surface foncée.

Les SVG intégrés aux pages CSS, EGK et SLKK sont extraits avec leurs tracés originaux, sans scripts ni attributs d'animation. Les couleurs EGK proviennent de la feuille de style officielle référencée dans la provenance. Les fichiers SVG sont normalisés en LF, sans espaces terminaux ; le SHA-256 porte sur l'actif local ainsi normalisé. Les images sont servies localement ; le navigateur du visiteur n'appelle pas les sites des assureurs pour les charger. Marques appartenant à leurs titulaires, utilisées pour identifier les offres, sans suggestion de partenariat.

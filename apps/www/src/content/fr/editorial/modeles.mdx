# Comparer des modèles de service

Ce tableau reprend la grille de positionnement du document produit. La colonne CoverView décrit le modèle cible du projet : les services, moteurs et fonctions de suivi mentionnés ne sont pas encore disponibles.

| Service                        | Agent de compagnie | Courtier traditionnel | CoverView                                      |
| ------------------------------ | ------------------ | --------------------- | ---------------------------------------------- |
| Accès à plusieurs solutions    | Limité             | Oui                   | Oui                                            |
| Analyse du contrat actuel      | Variable           | Variable              | Systématique lorsque les données le permettent |
| Benchmark du marché            | Rare               | Variable              | Structuré et documenté                         |
| Analyse des performances       | Rare               | Variable              | Oui                                            |
| Analyse des frais              | Partielle          | Oui                   | Détaillée et historisée                        |
| Analyse de l’allocation        | Rare               | Variable              | Oui                                            |
| Rapport comparatif             | Rare               | Rare                  | Oui                                            |
| Suivi périodique               | Variable           | Variable              | Structuré                                      |
| Réévaluation                   | Variable           | Variable              | Oui                                            |
| Outils numériques              | Variable           | Variable              | Wallet + moteurs + automatisations             |
| Approche data                  | Rare               | Rare                  | Centrale                                       |
| Centralisation du portefeuille | Non                | Rare                  | Wallet                                         |

## Comment lire cette grille

« Rare » et « variable » décrivent des tendances de modèle présentées par la source, sans mesure statistique fournie. Ces qualificatifs ne constituent pas une affirmation sur chaque professionnel. Les autres valeurs doivent également être replacées dans ce cadre : les prestations concrètes dépendent du professionnel, du mandat et des données disponibles.

Cette grille n’est ni une étude indépendante du marché ni une garantie de service universelle. Elle expose les dimensions que CoverView souhaite rendre explicites, sans prouver leur livraison.
